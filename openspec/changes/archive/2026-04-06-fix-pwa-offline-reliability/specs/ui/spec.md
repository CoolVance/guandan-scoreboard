## MODIFIED Requirements

### 侧边栏访问模式按钮
侧边栏 SHALL 包含一个按钮，用于显示当前连接/版本状态、离线就绪情况并触发强制刷新。

#### 场景：按钮状态指示灯
- **当** `version-management` 检测到更新时，显示**闪烁的绿色点**（优先级最高）。
- **当** 应用为最新版且 Service Worker **已完成预缓存**（离线就绪）时，显示**实心绿色点**。
- **当** 应用为最新版但 Service Worker **未就绪**时，显示**黄色点**。
- **当** 检测版本失败时，显示**灰色点**。
- **当** 网络离线时，显示**黑色点**。

### Requirement: 离线就绪文字反馈
当用户点击侧边栏的状态按钮时，系统 SHALL 显示明确的文字反馈告知当前的离线可用性。

#### Scenario: 点击显示状态详情
- **WHEN** 用户点击带有状态点的按钮
- **THEN** 弹窗或 Toast SHALL 明确显示：
  - “在线/离线” 模式
  - “离线功能已就绪 / 正在准备离线资源”
  - 当前应用版本号
